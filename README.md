# gelato-gtk3
## CODENAME Doohickey Two
-------------------------
The GELATO theme is a desktop environment theme heavily inspired by the Piapro Character KAITO, thus the appearance of his signature colours. In the future, this theme will be bundled with a Xfwm theme featuring KAITO's character elements, making it a derivative work. The license applied to the Xfwm-bundled version will change from the GNU General Public License to CC BY-NC.
